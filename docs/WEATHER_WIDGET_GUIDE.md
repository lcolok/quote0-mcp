## 🎯 使用方式

### 基础用法
```bash
# 默认使用robust模式 + maximized样式
npm run widget:weather 海珠区
npm run widget:weather 朝阳区 1    # 黑边框
npm run widget:weather 杭州       # 任意中国城市
```

### 高级选项
```bash
npm run widget:weather [城市名称] [边框] [数据源]

参数说明:
  城市名称: 任意中国城市名称 (默认: guangzhou)
  边框: 0=白色, 1=黑色 (默认: 0)  
  数据源: robust, smart, real (默认: robust)
```
