# 新闻组件14px字体优化记录

## 🎯 优化目标

根据用户建议，将新闻组件字体从12px进一步调整到14px，以获得更好的显示效果和阅读体验。

## 🔧 具体调整内容

### 1. 基础字体设置
```typescript
// 主容器
fontSize: '12px' → '14px'
lineHeight: '14px' → '16px'

// 所有子元素统一
fontSize: '14px'
lineHeight: '16px'
```

### 2. 布局参数适配
由于14px字体需要更多空间，相应调整了布局：

#### 文本截断长度优化
```typescript
// 主标题
{title.length > 35 ? ...} → {title.length > 30 ? ...}
截断位置: 32字符 → 27字符

// 摘要
{summary.length > 50 ? ...} → {summary.length > 45 ? ...}
截断位置: 47字符 → 42字符

// 列表项标题  
{item.title.length > 30 ? ...} → {item.title.length > 25 ? ...}
截断位置: 27字符 → 22字符
```

#### 显示内容数量调整
```typescript
// 新闻列表条目
items.slice(0, 5) → items.slice(0, 4)
显示条目: 5条 → 4条

// 列表项间距
gap: '2px' → gap: '1px'
间距优化: 更紧凑的布局
```

#### 编号列宽度调整
```typescript
// 列表编号最小宽度
minWidth: '12px' → minWidth: '14px'
适配14px字号的编号显示
```

## 🎨 字体技术分析

### 字体文件可用性
```bash
# 可用的像素字体尺寸
8px:  fusion-pixel-8px-monospaced-*.woff2
10px: fusion-pixel-10px-monospaced-*.woff2  
12px: fusion-pixel-12px-monospaced-*.woff2
14px: (暂无专用14px像素字体文件)
```

### 字体渲染机制
当指定14px时：
1. **CSS层面**: 使用14px作为font-size，影响行高和布局计算
2. **字体回退**: 系统使用最接近的12px像素字体文件
3. **渲染效果**: 12px像素字体 + 14px布局空间 = 更宽松的视觉效果

这种组合实际上产生了很好的效果：
- 保持了12px像素字体的清晰度
- 获得了14px布局的宽松间距
- 避免了字体缩放模糊的问题
