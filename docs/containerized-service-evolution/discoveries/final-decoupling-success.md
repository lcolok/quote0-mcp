## 🔧 解决的技术难题

### 1. 环境变量加载时序
**问题**：插件初始化时 .env 文件尚未加载，导致高德API密钥不可用
**解决**：实现懒加载机制，在实际使用时再初始化服务
```typescript
// 修复前：构造函数直接初始化
constructor() {
  this.amapService = new AmapWeatherService(); // ❌ 此时环境变量未加载
}

// 修复后：懒加载模式
private getAmapService(): AmapWeatherService {
  if (!this.amapService) {
    this.amapService = new AmapWeatherService(); // ✅ 使用时才初始化
  }
  return this.amapService;
}
```

### 2. 类型系统设计
**挑战**：如何在保证类型安全的同时支持不同组件的数据结构
**解决**：采用泛型约束的插件接口设计
```typescript
interface WidgetPlugin<TData = any, TConfig extends WidgetConfig = WidgetConfig>
```

### 3. CLI接口统一
**挑战**：统一不同组件的CLI参数解析和验证
**解决**：每个插件实现自己的 `parseCliArgs` 方法，框架负责统一调度
